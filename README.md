## 方法

三步：**提取**（把散落说法整理成结构）→ **核对**（查证据，标出源头讲错的地方）→ **归档**（不随平台流量消失）。

一条贯穿原则：**区分「一手经历」和「二手整理」**，并标明说话的人是谁 —— 「谁在说」经常比「说了什么」更能决定可信度。
